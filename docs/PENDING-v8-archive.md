# Yaliyobaki (hayajakamilika / yanahitaji wewe)
**Yanahitaji mazingira/credentials:** Supabase project + `DATABASE_URL`/`JWT_SECRET` (seva pekee), deployment ya FastAPI (HTTPS), release keystore (`android/key.properties`), simu ya majaribio, UAT.
**Hayajatekelezwa kwa kodi (kuwa wazi):**
- Pull sync (kupakua data kutoka seva) na UI ya kutatua conflicts; attachments upload kwenda Storage.
- User authentication ndani ya app (PIN ya zamani bado ina hash dhaifu FNV); RBAC ya app; witness kama mtumiaji aliyethibitishwa.
- Approval workflow ya matumizi, UI ya kuunganisha gharama na Batch, Batch merge, mashine/opereta/kemikali kwenye processing.
- Ripoti za PDF/Excel, filters kamili, pagination ya Global Search, Batch/Sale Traceability page, reminders za madeni, payroll ya hali ya juu.
- FK halisi za SQLite kwa majedwali ya v7 (zinalindwa na triggers badala yake), audit hash chain, localization ya Kiingereza.
- Docs: privacy policy, terms, user/admin guide, pilot plan, security report, app icon/branding.
- Viwango rasmi vya mrabaha/tozo: ingiza kupitia Viwango vya Kodi na chanzo.
