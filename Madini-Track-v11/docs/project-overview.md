# Madini Track Tanzania

## Project Goal
Build an offline-first, multi-company and multi-mine management platform for Tanzania.

## Technology Stack
- Mobile: Flutter
- Backend: Frappe Framework
- Server Database: MariaDB
- Local Database: SQLite
- Source Control: GitHub
- Development Environment: GitHub Codespaces

## Main Modules
1. Companies and Mines
2. Users, Roles and Permissions
3. Mine Production
4. Ore Batch Tracking
5. Ore Processing and Gold Recovery
6. Employees and Attendance
7. Payroll
8. Inventory
9. Expenses and Revenue
10. Sales and Payments
11. Reports and Dashboards
12. Audit Logs
13. Offline Data Synchronization

## Core Requirements
- Support multiple companies and mines.
- Isolate each company's data.
- Enforce mine-level user permissions.
- Work offline and synchronize when internet returns.
- Track ore from extraction to processing and sale.
- Maintain audit history for important changes.
- Prevent duplicate synchronization.
- Support Swahili as the primary user language.

## Development Principles
- Security first.
- Offline-first architecture.
- Modular and maintainable code.
- Commercially permissive dependencies where possible.
- No unverified third-party integrations.
